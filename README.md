
# 🌸 Shree – A Safe Space for Women

Shree is a simple, mobile-friendly website where women can share their stories anonymously, find support in communities, reach emergency helplines quickly, and learn how to stay safe.

**Live site:** https://arshi1-singhal.github.io/Shree-/

## Features

- Anonymous stories and supportive replies
- Communities: create, join and open topic-based groups
- Report button to hide harmful stories
- Emergency helplines with one-tap calling (112, 181, 1091, 1930, 1098, 108)
- SOS button that shares your live location through WhatsApp, SMS or the share menu
- Safety tips and legal rights
- Works on phones and computers, with dark mode

## Project structure

```
Shree-/
├── index.html   # Page structure
├── style.css    # Colors, layout, dark mode
├── app.js       # Stories, communities, SOS location
└── README.md
```

## Run it on your computer

1. Download this repository.
2. Keep `index.html`, `style.css` and `app.js` in the same folder.
3. Double-click `index.html` to open it.

## Deploy with GitHub Pages

1. Upload the files to the root of a public repository.
2. Go to Settings → Pages.
3. Set Source to "Deploy from a branch", then choose main and / (root).
4. After a minute or two, the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
